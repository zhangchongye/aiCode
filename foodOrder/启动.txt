本地怎么启动

● 小程序没有 npm run dev 这类命令行启动方式,必须用微信开发者工具(图形界面)运行。步骤:

  1. 安装并导入项目

  - 下载微信开发者工具(稳定版 Windows x64):https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
  - 打开工具 → 扫码登录 → 导入项目 → 目录选 C:\work\aiCode\foodOrder
  - AppID 填你自己的(没有就先去 mp.weixin.qq.com
    注册一个)。用"测试号"只能看界面,云能力全部不可用(登录/数据库/云函数都走云),所以点餐流程必须用真实 AppID

  2. 开通云开发(一次性)

  - 工具顶部工具栏点 "云开发" → 开通环境(免费额度)
  - 控制台 → 数据库 → 手动创建 4 个集合:users、categories、products、orders
  - 每个集合 → 权限设置 → 自定义规则:
    - products/categories:{ "read": true, "write": false }
    - users:{ "read": "doc._id == auth.openid", "write": false }
    - orders:{ "read": false, "write": false }

  3. 部署云函数(一次性)

  左侧资源管理器 → cloudfunctions 目录下 4 个函数(login、order、productAdmin、seed)逐个右键 →
  "上传并部署:云端安装依赖"。

  4. 运行

  - 点工具栏 "编译" → 模拟器出现点餐首页
  - "我的"页 → 初始化菜单数据(跑 seed,写入示例分类和菜品)
  - 之后每次改代码点编译即可,改云函数需重新上传部署

  命令行能做的只有单测

  cd C:\work\aiCode\foodOrder && node --test tests/*.test.js

  开发期模拟扫码:工具里 "编译模式" → 启动参数 填 scene=t%3D3(桌号 3),或普通编译后点首页"桌号"手动选。商家账号配置(把你的
  openid 置为 merchant)见 README 第 7 步。

  注意:project.config.json 里 appid 现在是占位的 touristappid,导入时工具会让你填真实 AppID,直接覆盖即可。
